# agentswf

agents.wf is an engine that runs workflows made of coding agents. This package gives you the
`awf` command and `agentswf/workflow`, the module a workflow imports.

> **Beta.** Interfaces will change between versions.

```sh
bun add -g agentswf@beta
awf run ./review.ts
```

It runs on Bun only. The README in the repository says what to install first and how to write a
workflow: [github.com/romanlv/agentswf](https://github.com/romanlv/agentswf).
