# Decisions

`foundation.md` carries the decisions taken together, because they argue with each other. A record
belongs here once a decision is made *against* that document — a boundary moved, a stage gate
changed, a rejected option revisited — and the reason would otherwise be lost in a commit message.

One file per decision: what was decided, what it replaces, and what evidence moved it.
